## 구성

```
├── index.html    수업 소개
├── apply.html    신청서 (한 번에 한 질문씩)
└── photos/       웹용으로 줄인 사진 (WebP)
```

빌드 도구가 없습니다. HTML 파일을 그대로 열면 동작합니다.

기획 문서, 인스타그램 카드뉴스, 접수 스크립트는 사이트 구동에 필요하지 않아 이 저장소에 두지 않습니다.

## 미리보기

```bash
python3 -m http.server 8765
```

- 수업 소개 — <http://localhost:8765/index.html>
- 신청서 — <http://localhost:8765/apply.html>

## 배포

**Settings → Pages → Source: Deploy from a branch → main / (root)**

`https://layeahangel.github.io/Layeah-Yoga/` 에서 열립니다. 빌드 과정이 없어 푸시하면 몇십 초 뒤 반영됩니다.

## 신청 접수

신청 내용은 구글 스프레드시트에 쌓입니다. `apply.html` 의 `ENDPOINT` 가 접수 주소입니다.

접수 주소는 페이지에 노출될 수밖에 없으므로, 출처를 막는 대신 **함정 칸 · 분당 제한 · 서버 검증** 세 가지로 걸러냅니다.
